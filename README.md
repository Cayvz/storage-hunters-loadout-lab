# Storage Hunters Loadout Lab

A free, single-page companion tool for organizing charms and four independent gavel loadouts.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Add charms and their displayed stats.
4. Equip charms separately on each gavel.

No installation, account, server, or paid API is required. Data is stored in the browser's localStorage. Use Export backup to save a JSON copy.

## Publish it free
You can publish the folder with GitHub Pages:
1. Create a GitHub account and a new public repository.
2. Upload `index.html` (and this README).
3. In repository Settings > Pages, choose deploy from the main branch and root folder.
4. Wait for GitHub Pages to publish the site.

## Monetization reality
The project has no ads, payment processing, or traffic built in. Those require publishing, an audience, and approval from an ad network or payment provider. Do not add ads until you meet the provider's current eligibility and policy requirements. Never promise users that this fan tool is official or affiliated with Roblox or the game developers.

## Limitations
- It does not connect to Roblox or fetch live game data.
- Enter charm names and effects manually from the game.
- The same charm can be equipped independently on multiple gavels, reflecting separate loadout planning.
- Stats are added as entered; the tool does not assume hidden game formulas.
